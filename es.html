GOOD TO KNOW

Antes de conectar.
Resolvemos tus dudas.

¿Puedo desplegar MingHe en Vercel?+

Esta web puede desplegarse directamente en Vercel. El servidor SIP de MingHe necesita un puerto TCP fijo para señalización y un rango de puertos UDP fijos para medios. Usa un VPS adecuado o tu propio servidor.

¿Qué clientes puedo usar?+

El proyecto recomienda Bria Mobile y Linkvil W610W / W620W. Otros clientes necesitan SIP sobre TLS, SDES-SRTP y ajustes adecuados de confianza de certificados. Estas funciones deben verificarse por separado en el Tantuns H5.

¿Cómo uso un certificado autofirmado?+

Importa certs/server.crt del servidor como certificado de confianza en el cliente y mantén activa la verificación. Actualiza la confianza del cliente tras cada renovación. Para despliegues públicos, usa un certificado de una CA de confianza.

¿MingHe es de código abierto?+

Sí. MingHe es de código abierto bajo la licencia Apache-2.0. Visita GitHub para consultar el código, informar de problemas o contribuir.
