GOOD TO KNOW

连接之前，
你可能想知道。

鸣鹤可以部署在 Vercel 上吗？+

本介绍网站可以直接部署到 Vercel。鸣鹤 SIP 服务器需要固定 TCP 信令端口和 UDP 媒体端口范围，请使用符合条件的 VPS 或自有服务器。

可以使用哪些客户端？+

项目文档推荐 Bria Mobile 和 Linkvil W610W / W620W。其他终端需支持 SIP over TLS、SDES-SRTP，以及适用的证书信任策略。Tantuns H5 需另外确认这些能力。

自签名证书要如何配置？+

将服务器的 certs/server.crt 导入客户端为受信任证书，并保持证书验证开启。自动续期后需更新客户端信任；公网使用建议配置受信任 CA 证书。

鸣鹤是开源项目吗？+

是的，项目以 Apache-2.0 许可证开源。你可以前往 GitHub 阅读源码、提交问题或参与贡献。
