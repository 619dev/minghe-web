The essentials for self-hosted voice, from signaling to media.

⌑01

Encryption in transit

TLS 1.2 / 1.3 protects SIP signaling; SRTP protects voice media. Individual extension passwords and Digest authentication are supported.

TLS + SRTP
⌘02

Pure Rust. Built with purpose.

A minimal SIP server built with memory-safe Rust and the Tokio async runtime, without garbage collection.

RUST NATIVE
↗03

Your network. Your control.

Deploy on your own VPS and manage internal extensions. Make voice calls and send SIP text messages, with temporary offline queuing and redelivery.

SELF-HOSTED

Encryption note: the server decrypts and re-encrypts relayed media, so it is part of the trust boundary. This is not end-to-end encryption. Offline messages are held in memory and lost on restart.

minghe / quick-start
# 01 Get the source
git clone https://github.com/619dev/minghe.git
cd minghe

# 02 Prepare configuration
mkdir -p config
cp config.template.toml config/config.toml

# Set host, media_addr, and all enabled passwords
vim config/config.toml

# 03 Build from current source and start
docker build -t facilisvelox/minghe:latest .
docker compose up -d

docker compose logs -f

GOOD TO KNOW

Before you connect.
A few useful answers.

Can I deploy MingHe on Vercel?+

This website can be deployed directly to Vercel. The MingHe SIP server needs a fixed TCP signaling port and a fixed UDP media port range. Use a suitable VPS or your own server.

Which clients can I use?+

The project recommends Bria Mobile and Linkvil W610W / W620W. Other clients need SIP over TLS, SDES-SRTP, and appropriate certificate trust settings. These capabilities need separate verification for the Tantuns H5.

How do I use a self-signed certificate?+

Import certs/server.crt from your server as a trusted certificate in your client and keep certificate verification enabled. Update client trust after renewal. For public deployments, use a certificate from a trusted CA.

Is MingHe open source?+

Yes. MingHe is open source under the Apache-2.0 license. Visit GitHub to read the code, report issues, or contribute.
