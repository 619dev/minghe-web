01 / BUILT TO CONNECT

가벼운 코어,
모든 통화를 소중하게.

복잡한 프로토콜을 간편한 경험으로.
시그널링부터 미디어까지, 자체 호스팅 음성 통신의 필수 기능을 제공합니다.

⌑01

전송 구간 암호화

TLS 1.2 / 1.3으로 SIP 시그널링을, SRTP로 음성 미디어를 보호합니다. 내선별 비밀번호와 Digest 인증을 지원합니다.

TLS + SRTP
⌘02

순수 Rust, 간결하고 강력하게

메모리 안전한 Rust와 Tokio 비동기 런타임으로 구축한 최소한의 SIP 서버입니다. 가비지 컬렉션이 없습니다.

RUST NATIVE
↗03

내 네트워크를 직접 관리

자신의 VPS에 배포하여 내선을 관리하세요. 음성 통화, SIP 문자 메시지, 오프라인 임시 보관 및 재전송을 지원합니다.

SELF-HOSTED

암호화 안내: 중계 서버는 미디어를 복호화한 뒤 다시 암호화하므로 신뢰 경계에 포함됩니다. 종단 간 암호화가 아닙니다. 오프라인 메시지는 메모리에 보관되며 재시작 시 사라집니다.

02 / GET STARTED

VPS 준비부터,
첫 “여보세요”까지.

고정 TCP / UDP 포트를 개방할 수 있는 서버를 준비하고,
Docker Compose로 MingHe를 시작하세요.

  1. 1
    소스 가져오기

    저장소를 복제하고 Docker와 Compose를 준비합니다.

  2. 2
    서버 설정

    서버 IP, 미디어 주소, 내선별 비밀번호를 설정합니다.

  3. 3
    단말기 연결

    TLS와 SDES-SRTP를 지원하는 SIP 클라이언트를 사용합니다.

전체 배포 가이드 ↗
minghe / quick-start
# 01 소스 가져오기
git clone https://github.com/619dev/minghe.git
cd minghe

# 02 설정 준비
mkdir -p config
cp config.template.toml config/config.toml

# host, media_addr 및 활성화된 모든 비밀번호 수정
vim config/config.toml

# 03 현재 소스로 빌드 후 시작
docker build -t facilisvelox/minghe:latest .
docker compose up -d

docker compose logs -f

배포 전에 포트를 개방하세요

5061 / TCP SIP 시그널링 · 20000–20020 / UDP 음성 미디어

공개 포트 매핑은 설정과 일치해야 합니다. Vercel은 이 소개 웹사이트를 호스팅합니다. MingHe 서비스에는 UDP를 지원하는 VPS가 필요합니다.

GOOD TO KNOW

연결하기 전에,
알아두면 좋은 정보.

MingHe를 Vercel에 배포할 수 있나요?+

이 소개 웹사이트는 Vercel에 바로 배포할 수 있습니다. MingHe SIP 서버에는 고정 TCP 시그널링 포트와 고정 UDP 미디어 포트 범위가 필요합니다. 적합한 VPS나 자체 서버를 사용하세요.

어떤 클라이언트를 사용할 수 있나요?+

프로젝트는 Bria Mobile과 Linkvil W610W / W620W를 추천합니다. 다른 단말기는 SIP over TLS, SDES-SRTP 및 적절한 인증서 신뢰 설정을 지원해야 합니다. Tantuns H5는 별도 확인이 필요합니다.

자체 서명 인증서는 어떻게 설정하나요?+

서버의 certs/server.crt를 클라이언트의 신뢰할 수 있는 인증서로 가져오고 인증서 검증을 활성화하세요. 갱신 후에는 클라이언트의 신뢰 설정도 업데이트하세요. 공개 배포에는 신뢰할 수 있는 CA 인증서를 권장합니다.

MingHe는 오픈 소스인가요?+

네. Apache-2.0 라이선스로 공개되어 있습니다. GitHub에서 소스 코드를 살펴보고 문제를 보고하거나 기여할 수 있습니다.
