GOOD TO KNOW

Vor dem Verbinden.
Gut zu wissen.

Kann ich MingHe auf Vercel bereitstellen?+

Diese Website lässt sich direkt auf Vercel bereitstellen. Der MingHe-SIP-Server benötigt einen festen TCP-Port für Signalisierung und einen festen UDP-Portbereich für Medien. Nutzen Sie einen geeigneten VPS oder einen eigenen Server.

Welche Clients kann ich verwenden?+

Das Projekt empfiehlt Bria Mobile und Linkvil W610W / W620W. Andere Clients benötigen SIP über TLS, SDES-SRTP und passende Einstellungen zum Zertifikatsvertrauen. Diese Funktionen müssen beim Tantuns H5 gesondert geprüft werden.

Wie verwende ich ein selbst signiertes Zertifikat?+

Importieren Sie certs/server.crt vom Server als vertrauenswürdiges Zertifikat im Client und lassen Sie die Prüfung aktiviert. Aktualisieren Sie das Vertrauen nach der Erneuerung. Für öffentliche Server empfiehlt sich ein Zertifikat einer vertrauenswürdigen CA.

Ist MingHe Open Source?+

Ja. MingHe steht unter der Apache-2.0-Lizenz. Auf GitHub können Sie den Code ansehen, Probleme melden oder mitwirken.
